知答 ZhiDa 架构

FastAPI + 本地 BGE/BM25 混合检索 + Qdrant 参数取自 config.py / .env.example
问答通路：问题 → FastAPI → 本地 BGE 稠密 + BM25 关键词 → 加权 RRF → 文档级聚合 → DeepSeek 流式生成 → 答案带 [n] 引用回链； 入库通路：上传 → 解析 → 分块 → 本地 BGE 嵌入 → Qdrant。两条通路共用 FastAPI 中间件，会话与限流可选走 Redis。
问答通路 问题 → 追问改写 → 稠密 + 关键词检索 → 加权 RRF → 拼上下文 → 流式生成 → 引用回链 在线请求

2nginx 统一入口
静态托管 chat.html

上传上限 25m
3FastAPI 中间件
认证：Cookie / API Key
限流 · TraceID · 审计日志
会话 / 限流 → Redis（可选）
4混合检索

k=60；文档级聚合，主文档优先
读 Qdrant：tenant_id / kb_id 过滤
5生成与回链

超时 60 秒 · 可配多轮
答案 [n] ↔ sources[] 引用
入库通路 上传 → 解析 → 分块 → 嵌入 → 写入 Qdrant；知识库按 tenant_id / kb_id 隔离 上传 / 离线
